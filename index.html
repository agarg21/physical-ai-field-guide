The curriculum

Four weeks from loop to lab

Each week has a bounded core, a tangible output, and optional depth that stays outside the time budget.

01

Robot fundamentals

Understand the closed loop

Build the vocabulary for bodies, frames, observations, actions, policies, controllers, and environments.

  1. 2.5h
    Rigid motion & kinematics

    Modern Robotics introductions and selected videos · L02

  2. 2h
    Manipulation as a system

    MIT introduction and robot/simulation chapter · L03

  3. 2h
    Dynamics & feedback

    Underactuated overview and CartPole example · L04

  4. 1h
    Draw the loop

    Annotate observation → decision → action for CartPole and an arm

Weekly output

A one-page explanation of the seven essential system concepts.

02

Simulation & learning

Connect software to behavior

See how robot software, physics environments, imitation learning, and reinforcement learning fit together.

  1. 1.5h
    Robot middleware

    ROS 2 concepts: nodes, topics, services, actions, bags · L05

  2. 2.5h
    Physics & task environments

    Run MuJoCo and Gymnasium examples · L06–L07

  3. 3h
    Behavior cloning & policy gradients

    Two selected CS285 lectures · L11–L13

  4. 1.5h
    Modern action generation

    Diffusion Policy overview and architecture · L14

Weekly output

A reproducible reset/step trace and an IL-versus-RL comparison.

03

Data & generalist policies

Read the VLA landscape clearly

Learn what robot datasets contain and compare generalist policies without losing track of embodiment or evidence.

  1. 3h
    Robot data in practice

    LeRobot datasets, policies, training, and evaluation · L08–L09

  2. 2.5h
    From RT-1 to cross-embodiment data

    RT-1, RT-2, and Open X figures and evaluations · L15–L17

  3. 2.5h
    Compare open generalists

    Octo, OpenVLA, SmolVLA, and π0 · L18–L21

  4. 0.5h
    Choose a frontier question

    Use the awesome list with a purpose · L01

Weekly output

A policy comparison table covering embodiment, inputs, actions, data, compute, and evidence.

  1. 1.5h
    End-to-end stack

    Selected NVIDIA architecture and workflow material · L10

  2. 1h
    Embodied reasoning

    Gemini Robotics architecture and evaluation · L22

  3. 2h
    Provenance & contracts

    Inspect revisions, execution boundaries, and platform differences

  4. 4h
    Design, run, report

    Answer one falsifiable question and preserve raw output

Weekly output

An experiment report with configuration, raw results, expectations, and interpretation.

A practical bias

Do not try to learn all of robotics in a month.

Learn enough structure to ask better questions. Run small things. Preserve evidence. Let each experiment tell you what to study next.
